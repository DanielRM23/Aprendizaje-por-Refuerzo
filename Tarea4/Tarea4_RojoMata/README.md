- **Descenso Escalarizado Multiobjetivo** (`Descenso.py`)

## Requisitos

Este proyecto fue desarrollado en **Python 3.10+** y requiere las siguientes librerías:

- `mo-gymnasium`
- `gymnasium`
- `numpy`
- `matplotlib`
- `pandas`
- `pymoo`
- `torch`

### Instalación

Puedes instalar todos los paquetes necesarios ejecutando los siguientes comandos:

```bash
pip install mo-gymnasium
pip install gymnasium
pip install numpy
pip install matplotlib
pip install pandas
pip install pymoo
pip install torch
```
